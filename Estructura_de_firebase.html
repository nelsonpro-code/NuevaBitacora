MÓDULO 1: TEORÍA ESENCIAL

Arquitectura Serverless y Estructura NoSQL

¿Qué es NoSQL (Firestore)?

A diferencia de las bases de datos relacionales tradicionales (que usan tablas, filas y columnas), Firebase Cloud Firestore organiza la información en un formato de Documentos y Colecciones, estructurado de forma casi idéntica a los objetos JSON de JavaScript.

  • Documento: Es una unidad de almacenamiento que contiene pares de clave-valor (ej. nombre: "Rey"). Su tamaño máximo es de 1 MB.
  • Colección: Es un contenedor de documentos. No puede contener valores directamente, solo almacena documentos.

Visualmente, la estructura lógica se modela de la siguiente manera:

[Colección: "usuarios"] └── [Documento: "ID_usuario_1"] ├── nombre: "Rey" ├── rol: "Master Developer" └── [Colección Secundaria: "apuntes"] (Opcional)

Integración Limpia en HTML (Modo CDN)

Inicializar las instancias const app = initializeApp(firebaseConfig); const db = getFirestore(app); // Tu código interactivo comenzará aquí abajo... </script>
MÓDULO 3: PRÁCTICA DE OPERACIONES (CRUD)

Manipulación de Datos con JavaScript Asíncrono

Dado que las conexiones a la nube toman tiempo de red, Firebase utiliza promesas de JavaScript mediante el patrón de diseño async / await.

Operación 1: Guardar un apunte (Crear / Add)

// Función asíncrona para guardar notas de programación async function guardarApunte(titulo, contenido) { try { // Apunta a la colección "apuntes" e inserta un objeto JSON const docRef = await addDoc(collection(db, "apuntes"), { titulo: titulo, contenido: contenido, fecha: new Date() }); console.log("Documento guardado con ID: ", docRef.id); } catch (error) { console.error("Error al guardar datos: ", error); } }

Operación 2: Leer los apuntes guardados (Leer / Get)

// Función asíncrona para descargar y mostrar la información async function obtenerApuntes() { try { const querySnapshot = await getDocs(collection(db, "apuntes")); querySnapshot.forEach((doc) => { // doc.data() extrae las variables del objeto guardado console.log(`ID: ${doc.id} => `, doc.data()); }); } catch (error) { console.error("Error al leer datos: ", error); } }
